# Security Policy

## Reporting a vulnerability

Do not include student, instructor, medical, enrollment, credential, or other
operational data in a public issue. Report suspected vulnerabilities privately
to the repository maintainers through the private security-reporting channel
configured for the repository.

Until that channel is configured, contact the Aqua Essence maintainers
directly and provide only the minimum synthetic reproduction needed.

## Supported version

Version 1.1.0 on the default branch is the supported production baseline for
internal Chrome and Edge distribution. A Firefox package is generated from the
same source but has not received live validation for the current rollout. No
public browser-store release is currently supported.
